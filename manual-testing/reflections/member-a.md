1. What makes a test positive or negative?

A positive test checks whether the system accepts valid inputs, while a negative test checks whether it correctly rejects invalid inputs.

2. Why can a negative test pass?

A negative test can pass when the system correctly rejects an invalid input, as expected.

3. How did equivalence partitioning help you select data?

Equivalence partitioning helped us divide the age values into three groups: below 18, between 18 and 80, and above 80. Instead of testing every possible age, we selected one representative value from each group, making our testing more efficient.

4. What did boundary testing help you investigate?

Boundary testing helped us check whether the form correctly handles values at and around the minimum and maximum accepted ages. For example, I tested Ages 17 and 16 to check whether the form correctly rejects values below the minimum age of 18.

5. What did you choose to test during the open-ended activity, and why?

I chose to test age validation and error recovery because users may accidentally enter an invalid age. I wanted to find out whether the form would allow users to correct their input and submit successfully.
